## 验证与剩余边界

- 全量 C++ 主机回归 `python3 tests/run_host_tests.py` 通过；新增回归覆盖 NVS 键别名、启动日志、PWM 组合、MAVLink 参数列表 ID 的读写回环、MAVLink 手动源与输出队列、配网门户路由策略、Web 控制租约。离线评估工具的 4 个聚焦 Python 测试通过；嵌入网页脚本经 `node --check` 通过。
- 含 `4f086c2` 的最终镜像在三个目标板型编译通过：ESP32 Flash 1,313,563 B（66%）、RAM 124,348 B（37%）；ESP32-S3 Flash 1,294,940 B（65%）、RAM 124,156 B（37%）；ESP32-C3 Flash 529,472 B（26%）、RAM 71,820 B（21%）。
- ESP32 IPC-only 诊断构建在 `PartitionScheme=min_spiffs` 下通过：Flash 1,316,471 / 1,966,080 B，RAM 124,332 B。默认 1.3 MB 应用分区装不下当前诊断镜像，`1a74a12` 已更新构建脚本和说明。未刷写诊断镜像。
- 用户此前明确允许向这台 USB 设备刷写。对 `/dev/cu.usbserial-10` 上的 ESP32-D0WD-V3（MAC `20:50:0d:33:58:40`）更新最终镜像时，Arduino 上传程序在应用区约 91% 处失去连接，降速重试也中断；改用 esptool `--no-stub` ROM 模式、115200 baud 后，启动区、分区表和完整应用镜像均写入且写后哈希通过。RTS 复位后串口 `diag brief` 返回 `armed=0 imu_ok=1 motor_ok=1 battery_mv=4077 faults=0x00000000`。
- 本轮未解锁或驱动电机。Web 多页面交互、配网热点可见性、实际 ESC 脉宽、射频拥塞、负载下姿态和带桨飞行仍需相应硬件条件下验收；主机测试、编译、写后哈希与上锁自检不能替代这些验证。
