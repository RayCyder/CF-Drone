# 飞行停机安全复核（2026-10-04）

## 范围

本轮聚焦解锁后的终止路径和上锁后的零输出约束：遥控失联、IMU 失效、迫降、倒置、主循环阻塞、Web 急停和调试电机试转。

## 发现与修复

1. **迫降没有终止条件**：旧逻辑可长期保持约 42% 目标推力。现在迫降最长 8 秒，到期由独立任务直接写零电机 PWM，再由恢复的主循环同步上锁状态。
2. **倒置保护会空中直接停桨**：持续倒置 0.5 秒后改为请求水平恢复和受控迫降，不再直接上锁；最终仍受迫降 8 秒上限保护。
3. **主循环冻结会保留上次非零 PWM**：电机输出每次刷新都写心跳。解锁且有非零输出时，若 250 ms 未刷新，核0高优先级安全任务锁存迫降请求；主循环恢复后在下一次电机输出前进入受控迫降。若主循环持续冻结 8 秒，独立任务才将四路写零，兼顾空中短暂停顿和永久卡死。
4. **输出心跳存在跨核时间戳竞态**：安全任务可能先读取当前时间，主循环随后发布更新的心跳；旧的无符号减法会下溢并误判为超时。现在使用有符号回绕安全比较，并在发布“非零输出”标志前先发布对应时间戳。
5. **Web 失联的最终停机依赖主循环**：独立任务直接监视 Web 最后更新时间，失联与迫降总时限到期后强制停机；Web 快速上锁和急停仍直接走独立硬停机通道。
6. **独立截止原因丢失**：紧急截止锁存迫降超时、Web 失联、持续主循环停顿或 Web 急停原因。主循环恢复后写入 `HARD_STOP` 系统事件并保留上锁原因；短暂主循环停顿记录 `LOOP_STALL` 并转入迫降。
7. **安全任务创建失败仍可解锁**：独立飞行停机任务或 Web 快速停机任务未就绪时，解锁检查直接拒绝解锁。
8. **调试电机试转依赖主循环计时**：使用 `esp_timer` 独立一次性定时器写零；定时器创建或启动失败时拒绝试转。
9. **ESP32-D 内部 DRAM 链接溢出**：控制台历史从 46 行减为 44 行，回收 480 B 静态内存，固件重新链接通过。
10. **迫降期间人工输入无法恢复控制**：物理 RC、Web RC 或 MAVLink 的有效输入持续超过 300 ms，且油门达到 10% 或任一姿态轴偏转达到 15% 时，切回 STAB 并在当前控制周期恢复人工控制。短包、旧包和中位噪声不能解除迫降。
11. **自由落体未主动恢复推力**：解锁后使用校准机体系加速度检测；模长低于 0.3 g 持续 50 ms 时记录 `FREE_FALL` 并立即进入既有受控迫降。单个异常样本不会触发。
12. **上锁状态的输出边界不清晰**：普通飞行输出只有在 `armed=true` 时允许；受独立停止定时器约束的开机、网页和串口电机自检是唯一例外。自由落体只在已解锁时生效，日志、参数写入及其他请求不能启动电机。
13. **单帧 IMU 异常会立即上锁**：丢帧改为保留最后一个有限估计状态；有效样本连续中断 100 ms 后进入有时限迫降。只有估计器内部状态非有限、IMU 初始化失效或电机输出初始化失效仍立即上锁。

## 既有验证记录

- 下列结果来自本轮安全策略修改之前：主机回归、Web 页面回归、ESP32-D 与 ESP32-S3 编译曾通过。
- 本次“上锁强制零输出、IMU 丢帧迫降、倒置不直接停桨”修改尚未重新编译、运行主机回归或刷写设备；不得把旧结果作为本次修改的验证结论。

## 仍需实机验证的边界

- 8 秒迫降上限不是触地检测。从较高高度失联时，可能在触地前停机。
- 250 ms 主循环停顿阈值会触发受控迫降；它不再直接切断空中推力。若主循环持续冻结，电机保持最后输出最多约 8 秒后由独立任务写零。该时间是失控持续输出与高空断电之间的折中，仍需实机验证。
- 倒置保护仍需主循环持续得到有效姿态。识别后会尝试水平恢复和迫降；若主循环先冻结，输出心跳保护会请求迫降，并在持续冻结 8 秒后独立停机。
- 自由落体检测依赖有效 IMU 样本，并将近零比力作为判据；剧烈抛掷或特殊机动可能满足条件。300 ms 持续人工输入可立即接管，阈值仍需无桨台架和系留飞行复核。
